# Tokonatsu-Promenade
Unity で作成した２Dアクションゲームです。基本操作としてADで移動、Wでジャンプや空中ジャンプ、Ｓキーでしゃがみ及びすり抜け床をすり抜ける、Ｑキーで梯子を登る、がある。重力と地面、すり抜け床、動くリフトがある。背景はプレイヤーに追従するものとプレイヤーの移動によって左右へ流れるもの、そして地面と接続しているように見えるものがある。敵は近づくと出現し、横に移動し続け、壁にぶつかると方向を変え、接触でダメージ、踏むことで倒せる。動くリフトは乗ると自機が動くリフトに追従するようにした。（最初のリフトのみバグで追従しない）緑のクリスタルに触れるとゲームクリアとなる。落下してしまったり、敵にぶつかりすぎるとゲームオーバーとなりスペースキーでリスタートできる。
動くリフトの実装、モーション管理にすごく苦戦しました。
